# Bob Tronics

This repository contains the Bob Tronics project.

## Structure

- `frontend/` — Next.js application
- `backend/` — backend services and API code
- `docs/` — design and project notes

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

Then open http://localhost:3000

## Production build

```bash
cd frontend
npm run build
npm run start
```
